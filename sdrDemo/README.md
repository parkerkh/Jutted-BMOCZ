## SDR Demo

This folder contains a MATLAB live script that walks through an SDR implementation of a non-coherent and pilot-free BMOCZ-based OFDM transceiver. The demo assumes you have ADALM-PLUTO SDRs, though it can be readily edited for use with other SDRs. If you do decide to use PLUTO SDRs, however, you will require MATLAB's "Communications Toolbox Support Package for Analog Devices ADALM-Pluto Radio", which can be installed from the add-on explorer.
