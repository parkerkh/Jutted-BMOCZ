# ACPC Arrays

This folder contains arrays needed for the (31,16) and (127,106) affine cyclically permutable code (ACPC) implementations [5]. 

**Note:** you can load the arrays using the `loadACPCarrays()` function in the `/functions` folder of this repository. See `mainACPC.mlx` in the `/examples` folder for an example of how to use the associated encoding/decoding functions.
